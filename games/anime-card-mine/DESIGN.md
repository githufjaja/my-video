# Anime Card Mine — дизайн v2 (объединение двух референсов владельца)

Референсы (видео владельца, 04.10.2026, `out/2026-10-04-roblox-refs/`):
- **Реф 1 — «меч/тренировка»:** удар мечом даёт Power; зоны тренировки (+1/+2/+5/+10/+25 Power, требуют Wins);
  стены, которые надо разрушить, чтобы пройти дальше (уровень/стадия); таймер вверху «Sword Drop in 0m 6s» —
  раз в N минут с неба падает меч, «Find it first to collect it», исчезает через ~1.5 мин; Forge (крафт мечей
  по требованиям); инвентарь Pets / Swords / Charms (3 слота); Rebirth (x101 → x103 Power, сброс уровня);
  Worlds (World 7 locked — «Complete World 6 first»); Offline Reward с кнопкой «Double it!»; Auto Win; x2 Wins / x2 Power
  (донат); полоса Level внизу + кнопки «+10T / +100T / +1Qa»; Leaderboards; Tutorial-подсказки сверху.
- **Реф 2 — «аниме-карточки»:** верхние кнопки Plaza / Base / Sell; карточки стоят на базе и дают Cash/s;
  Index (коллекция, % собранного, мутации: Golden, Diamond, Venomous, Rainbow, Sakura, Candy, Blessed, Glitch, Starfallen,
  Radioactive); Items — зелья (Cash, Luck, Mutation, Production, Time I–IV) с таймерами активных бустов внизу справа;
  справа «2x Luck» и «Master Pack» за Robux; Luck 6.57x / Cash 10.98x — множители на экране; Boss Raid (башня с этажами),
  Raid Shop; аксессуары (+% Cash, +% Luck); VIP-зона, Starter Pack.

Брать ТОЛЬКО механики. Имена, арт, интерфейс — свои. Персонажи — оригинальные, без реальных аниме.

## Основной цикл (что хочет владелец)
1. **Режешь мечом препятствия** (камни/стены/блоки) → деньги + опыт силы. Разрушил стену стадии → проход на
   следующую стадию; несколько стадий = мир; новый мир открывается после прохождения предыдущего (как в реф 1).
2. **Каждые 90 секунд падает аниме-карточка** — таймер вверху «Card Drop in 1m 23s». Карточка падает с неба
   рядом с игроком (своя у каждого игрока — без драки за дроп), светится лучом по цвету грейда, подбирается касанием,
   исчезает через 60 с, если не подобрал. Грейд по шансам зоны + Luck; шансы видны в окне Odds.
3. **Карточку можно:**
   - **вставить в меч** (слоты меча, 1–3 → больше с апгрейдом/донатом): даёт +% урона / +% денег за удар;
   - **поставить на базу** — пассивный доход/сек (как сейчас, и в оффлайне — Offline Reward с «Double it!»);
   - **продать / скормить** другой карточке → уровень карточки (дубликаты).
4. **Меч** улучшается: уровень меча за деньги (+урон), смена меча (Forge: новый меч за деньги + карточки нужных грейдов).
5. **Rebirth**: сброс денег/стадии → постоянный множитель (карточки и коллекция сохраняются).
6. **Index** (коллекция карточек) — % собранного, награда за заполнение ряда. Мутации карточек (Golden/Rainbow…) — этап 3.
