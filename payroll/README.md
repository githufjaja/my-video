# Расчёт зарплаты по мотивации

Агент `payroll` (см. `.claude/agents/payroll.md`).

Как пользоваться: в чате с главным агентом пришлите файл мотивации за месяц и таблицы
выполнения и напишите, за какой месяц считать. Можно добавить фактически начисленные суммы —
агент покажет расхождения. Если данных не хватает, он вернёт вопросы.

Данные лежат в `payroll/data/<ГГГГ-ММ>/` — эта папка **не попадает в git**
(зарплаты — личные данные). Облачная сессия временная: итоговые файлы агент отправит в чат,
сохраните их у себя.
